# 小红书拆解书籍工程

## 一句话简介

一套面向建筑、城市与设计书籍的小红书内容生产工作流，将资料研究、图片溯源、内容拆解、图卡生成和发布文案整理成可重复执行的流程。

## 解决的问题

一篇高质量书籍图文并不只是“让 AI 写文案”，还需要核对书目信息、理解核心观点、寻找可公开使用的图像、设计 3:4 卡片、检查图文关系并记录来源。手工处理步骤多、重复劳动大，也容易发生选题重复和素材失去出处的问题。

## 核心功能 / 流程

选题查重 → 书目与内容研究 → 图片检索与来源记录 → 内容拆解 → 3:4 图卡生成 → 预览与人工质检 → 发布文案 → 成品归档。

- 使用书目登记表避免重复选题，并记录作者、书名和完成状态。
- 按“一本书一个清晰命题”设计 6—10 张连续图卡。
- 通过 Python 脚本批量生成 1242 × 1660 的 3:4 JPG。
- 每套内容保留预览图、发布文案、结构化清单和图片来源说明。
- 设置人工审核节点，检查标题、裁切、真实书封、项目图片与版权来源。

## 我的工作

- 设计从研究到发布准备的端到端工作流和内容质量标准。
- 建立书目查重、素材归档、图源记录和成品目录规范。
- 为不同书籍与刊物编写和迭代自动化生成脚本。
- 将抽象理论转化为适合移动端阅读的标题、视觉层级和卡片叙事。
- 根据早期发布数据复盘封面命题、内容节奏和收藏价值。

## 技术 / AI 能力

Python · Pillow · Content Workflow · AI-assisted Research · Structured Output · Visual Storytelling · Human-in-the-loop · Source Traceability

## 截图或示例

代表性成品包括《向拉斯维加斯学习》《癫狂的纽约》《建筑氛围》、建筑大师书籍系列，以及 Casabella / PIN–UP 刊物专题。正式上传版将选取少量已核对来源的预览图，不公开完整素材库。

## 当前状态

项目持续使用中。截至现有登记，已完成 60 本建筑与设计书籍，并制作多个刊物专题。工作流已覆盖选题、研究、素材、生成、质检、文案和归档；发布仍保留人工确认，不进行无人审核的自动发布。
