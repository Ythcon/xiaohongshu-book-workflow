# 三组图文的视觉系统

只在选择或调整视觉语言时读取。共同原则：先确定书籍或单期的核心命题，再把命题变成贯穿整套图卡的阅读操作；案例证明命题，图形只组织信息。

## 1. Signage｜《向拉斯维加斯学习》

适用：城市信息、商业符号、交通速度、大众文化、传播与识别。

核心转译：把“城市是一套从移动中读取的信息系统”转成远距离标题、招牌式关键词、强色条和案例序列。不是“赌场霓虹风”。

版式：

- 黑色信息面板 + 高饱和黄/粉/蓝点色。
- 案例照片占上部约 60%；下部独立文字面板，不让正文压住主体。
- 标签像道路标识，短、远距离可读；每页换一种主点色，但维持黑底和左侧色条。
- 封面使用问题：“为什么建筑师要向赌场招牌学习？”类型的认知冲突。
- 案例链：汽车尺度 → 标识先于建筑 → 建筑本身是符号 → 普通体量靠符号沟通 → 总结。

避免：泛用霓虹、赌场装饰、多个项目平均竞争、只有书名没有问题。

## 2. Anchoring｜斯蒂文·霍尔《锚》

适用：场地、地形、材料、光线、身体经验、建筑与环境关系。

核心转译：把“形式由场地关系生成”转成克制的场地拼贴、关系线、材料色和现象标签。不是字面船锚或航海图标。

版式：

- 暖白纸色、炭黑、朱红为骨架；钴蓝、黄、绿只标记不同关系。
- 封面可用 AI 拼贴底图，但必须在生成后覆盖核验的真实书封。
- 案例图保持完整建筑轮廓；下部独立浅/深信息区。
- 关系线、等高线、水彩痕迹必须说明场地/路径/光，不作装饰。
- 案例链：城市与景观 → 光与仪式 → 结构与生活 → 建筑群与公共城市 → 一句话总结。

避免：字面锚、绳索、海洋意象、地产广告感、过度水彩、虚构建筑轮廓。

## 3. Event Grid｜伯纳德·屈米《红不只是一种颜色》

适用：空间与事件、程序、运动、向量、规则、概念与形式。

核心转译：把“概念组织空间、程序、运动和事件”转成网格、红色规则、方向箭头与案例序列。红色是坐标和触发器，不是装饰色。

版式：

- 黑、白、屈米红为主；全套只使用一个高识别红。
- 技术网格贯穿，但透明度低，不能破坏照片阅读。
- 箭头只标示方向、路径或事件关系，禁止无意义加箭头。
- 照片上部、黑色信息区下部；红色竖线建立系列统一。
- 案例链：红色坐标 → 点线面规则 → 新旧并置产生程序 → 场地路径内容交汇 → 一句话总结。

避免：把红色等同视觉风格、网格盖住建筑、伪造理论引语、用复杂图解代替清楚案例。

## 选择规则

用一句话测试：

- 读者需要“看懂信息如何被传播” → `signage`。
- 读者需要“看懂建筑如何与具体世界发生关系” → `anchoring`。
- 读者需要“看懂规则如何组织行动与空间” → `event-grid`。

若三者都不匹配，仍沿用六页结构，但从书的命题发明一个新的视觉操作符；不要混搭三套表面元素。
